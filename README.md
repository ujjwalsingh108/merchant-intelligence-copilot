# Merchant Intelligence Copilot

__Architecture diagram, setup instructions, and API docs__

A conversational BI agent for e-commerce merchants to query their transactional data (orders, revenue, cancellations) in natural language, generating automated root-cause analysis and visualizations. We will use the Olist Brazilian E-Commerce Dataset (a real-world relational database with 100k+ orders, reviews) loaded into a PostgreSQL instance.
